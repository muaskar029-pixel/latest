What Radova Linux Is For

Author
Radova Team
Published
14 Nov 2026
Reading time
2 min read
Tags
introduction, architecture

Radova Linux is an operating system built for institutional memory: libraries, archives, and the digital assets they hold. Its aim is that an institution can boot a machine, sign in, and start managing its collections, without first spending a weekend installing and connecting separate archival software.

The project sums up its approach in one line: keep it simple.

Four applications, one system

Radova Linux ships with four information-management applications already installed and integrated:

  • Memora for library operations.
  • Evrocks for archives.
  • Coretez for digital asset management.
  • Linkers for institutional repositories and academic works.

Each one is available from the desktop right after booting. There is no external archival software to set up by hand.

Simple, secure, fast

Simple

The applications come pre-installed and pre-configured, so the system is ready for work as soon as it starts.

Secure

Radova Linux relies on strict Linux kernel security and access controls, uses full-disk encryption to protect institutional records, and collects no telemetry. The institution keeps complete ownership of its catalogs, archives, and digital files.

Fast

Unnecessary background processes are stripped out, so the hardware can spend its time on large catalogs and media files.

Modest hardware

Radova Linux is meant to run on the computers libraries and archives already have, not on flagship hardware.

Where it is headed

The project’s vision is to become a modern operating system that preserves and manages information for the future. Its mission has four parts:

  • Integrate information management applications into one ecosystem.
  • Provide solutions for managing information.
  • Support information preservation through structured, secure, and sustainable management.
  • Simplify how information is stored and used.
