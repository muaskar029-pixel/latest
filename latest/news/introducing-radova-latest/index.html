Introducing Radova Latest

Author
Radova Team
Published
14 Nov 2026
Tags
announcement, website

Today we are opening Radova Latest, a single place to follow what is happening around Radova Linux. Everything new appears here, newest first.

What you will find here

  • Agenda: community events and discussion sessions, with times in WIB (UTC+07:00) and a calendar file you can add to your own calendar.
  • Article: in-depth articles on how Radova Linux is built and the thinking behind it. The first one, What Radova Linux Is For, is already up.
  • News: announcements, releases, and project updates, like this one.
  • Security: security advisories, each with an ID, a severity level, the affected versions, and how to stay safe.

Light by design

Radova Latest is plain HTML. It loads quickly, works without JavaScript, and reads cleanly in text-only browsers such as Lynx.

This is a soft launch. The Agenda and Security sections are still empty, and new posts will appear here as the project develops.
